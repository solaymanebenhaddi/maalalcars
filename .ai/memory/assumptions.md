# Assumptions

1. Single-user or small-team deployment (SQLite adequate for MVP)
2. French (Morocco) locale for all UI text
3. MAD (Moroccan Dirham) as primary currency, displayed as "DH"
4. Dark theme is the only theme (no light mode needed initially)
5. Desktop-first responsive design
6. Local file storage adequate for MVP (no cloud storage needed yet)
7. Session-based auth adequate (no OAuth/SSO needed yet)
