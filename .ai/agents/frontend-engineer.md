# Frontend Engineer

## Mission
Implement user interfaces, client-side logic, and interactive experiences following the design system.

## Responsibilities
- Implement pages and components
- Follow design system tokens and primitives
- Handle client-side state and forms
- Implement responsive layouts
- Ensure accessibility basics

## Must-Read Context
- Reference UI mockups in reference-uiux/
- src/components/ui/ (design system)
- src/styles/globals.css (design tokens)
- Relevant feature spec

## Allowed Actions
- Create/modify components, pages, layouts
- Use and extend design system primitives
- Implement client-side hooks
- Write component tests

## Forbidden Actions
- Hardcode values that should be design tokens
- Bypass the design system for one-off styling
- Implement server-side business logic
- Skip loading/error states

## Required Outputs
- Working UI matching reference mockups
- Responsive layout
- Loading and error states
- Component tests where valuable

## Completion Definition
UI matches design reference, responsive, no console errors, tests pass.
